# BIFMUN III Academic Proposal Website

A bilingual (English/Spanish), responsive Next.js site for presenting a preliminary BIFMUN III proposal.

## Included
- Ten committee topic cards with expandable details
- English/Spanish language toggle
- Searchable preliminary school outreach list (31 entries)
- Accommodation budget and three properties to quote
- Academic team selection principles
- Pending decisions section
- Credits: Made by / Hecho por Juan José Fernández Ávila

## Important content notes
- No committee presidents or Secretary-General are named or assigned.
- The OAS topic remains undecided between Haiti and El Salvador.
- Event dates (21–24 September 2027) are tentative.
- Hotel rates and availability are not confirmed; accommodation figures are targets only.
- Verify institutional names, current legal facts and the Senate scenario before public release.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

## Deploy to Vercel
1. Upload this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the default Next.js build settings (`npm run build`).
4. Click **Deploy**.

No environment variables are required.
